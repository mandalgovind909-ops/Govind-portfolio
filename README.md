# Govind Mandal - Personal Portfolio

A premium, modern, and professional personal portfolio website for Govind Mandal, a Data Analyst & Power BI Developer.

## Features

- **Semantic HTML5 & Modern CSS3**: Built without heavy frameworks for maximum performance and clean code.
- **Mobile-First Responsive Design**: Adapts perfectly to all screen sizes, from mobile phones to ultra-wide monitors.
- **Dark Technology Aesthetic**: A premium color palette featuring deep navy backgrounds with electric blue and cyan accents.
- **Interactive UI**: Includes a sticky glassmorphism navbar, mobile hamburger menu, and smooth scroll reveal animations.
- **Data Analytics Showcase**: Specially designed CSS-only dashboard mockups to highlight data visualization skills.
- **SEO Optimized**: Includes meta tags, Open Graph data, and semantic structuring.
- **Client-Side Validation**: Built-in contact form validation.

## Setup & Customization

1.  **Open the project**: Simply open `index.html` in any modern web browser to view the portfolio.
2.  **Add your details**: Search for `[Add ...]` throughout the `index.html` file to replace placeholders with your actual information (e.g., links, resume, images).
3.  **Customize styling**: All main colors, typography, and spacing are controlled by CSS variables at the top of `css/style.css` in the `:root` pseudo-class.

## Technologies Used

- HTML5
- CSS3 (CSS Variables, Flexbox, CSS Grid)
- Vanilla JavaScript
- [Lucide Icons](https://lucide.dev/) (via CDN)

## Performance

The project is built to achieve high Lighthouse scores by:
- Avoiding heavy external frameworks (Bootstrap, Tailwind).
- Using system fonts combined with highly optimized Google Fonts (`Inter`).
- Implementing lightweight custom animations using Intersection Observer.
